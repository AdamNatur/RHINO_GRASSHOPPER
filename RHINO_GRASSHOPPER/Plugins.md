1. [CrossGems 3D Jewelry plugin for Rhino 8 - CAD Jewelry School](https://www.cadjewelryschool.com/cross-gems-3d-jewelry-plugin-for-rhino-7) — CAD-инструментарий для дизайна и производства ювелирных изделий: кольца, камни, оправы, декоративные элементы.
2. [Pufferfish](https://www.food4rhino.com/en/app/pufferfish) — 330+ компонентов для tween/blend/morph/интерполяций между точками, кривыми, мешами и поверхностями (Shape Changing).
3. [Dendro](https://www.food4rhino.com/en/app/dendro) — объёмное (воксельное) моделирование на базе OpenVDB: булевы операции, сглаживание, оффсеты и морфинг мешей.
4. [Nuclei](https://www.food4rhino.com/en/app/nuclei) — симуляция частиц по типу slime mold/муравьиных колоний: генеративные ветвящиеся сети и воксельные пространственные поля.
5. [Nautilus](https://www.food4rhino.com/en/app/nautilus) — 250+ компонентов: спирали, reaction-diffusion на мешах, лабиринты, одиночные пути для 3D-печати.
6. [nGon](https://www.food4rhino.com/en/app/ngon) — работа с n-угольными мешами (создание, адъясентность вершин/рёбер/граней, subdivide, planarize) и методы деревянных соединений.
7. [PanellingTools](https://www.food4rhino.com/en/app/panelingtools-rhino-and-grasshopper) — официальный плагин McNeel для панелирования поверхностей: 2D/3D паттерны на UV-сетке, параметрические аттракторы в Grasshopper.
8. [FreeJewels](https://www.food4rhino.com/app/free-jewels) — набор команд для ювелирного моделирования: паве-сеты (FJ_PaveSet), вставка сверл/камней, ориентация объектов на поверхности, расчёт веса изделия.
9. [Vectorize](https://www.food4rhino.com/en/app/vectorize#downloads_list) — трассировка растровых изображений в векторные кривые (на основе Potrace), есть компонент для Grasshopper.
10. [Parakeet](https://www.food4rhino.com/en/app/parakeet) — генерация алгоритмических паттернов и тайлингов (в т.ч. исламские звёздчатые узоры, паттерны в стиле M.C. Escher).
11. [Weaverbird](http://www.giuliopiacentino.com/weaverbird/) — топологический модификатор мешей: операторы subdivision и трансформации.
12. [Parachute](https://github.com/karamme/Parachute) — виджет, подписывающий имена компонентов прямо на канвасе Grasshopper.
13. [RhinoPolyhedra](https://www.food4rhino.com/en/app/rhinopolyhedra) — генерация 650+ многогранников, геодезических куполов, зоноэдров и мешей-сфер; доступен как команды Rhino и компоненты GH.
14. [Flexibility](https://www.food4rhino.com/en/app/flexibility) — 300+ компонентов для генерации и манипуляции геометрией (SubD, меши, NURBS, кривые), написан на C#.
15. [KeyshotStudio](https://manuals.keyshot.com/plugins/Rhinoceros.htm) — интеграция Rhino с KeyShot: прямая передача 3D-модели для рендеринга и визуализации.
